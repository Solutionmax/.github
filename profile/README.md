# SolutionMAX

We build self-hosted tools for hosting resellers and small teams — software that runs on the
hosting you already pay for, checks itself, and does not phone home. Based in Spain, working
with customers in the Netherlands, Belgium and Spain.

## Products

| | | |
|---|---|---|
| **Pharos** | A status page that runs its own HTTP, TCP and heartbeat checks, opens the incident when something fails and closes it when it recovers. Cachet 2.x compatible API. Runs on cPanel, DirectAdmin, Plesk, any PHP 8.3 host, or Docker. AGPL-3.0. | [pharos.solutionmax.net](https://pharos.solutionmax.net) · [docs](https://pharos.solutionmax.net/docs.html) |
| **Portalis** | A self-hosted SSH gateway: one entry point in front of your servers, every session recorded, access that expires by itself. | [portalis.sh](https://portalis.sh) |

Both are built and run by SolutionMAX and used on our own infrastructure first.
